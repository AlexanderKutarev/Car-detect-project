# Car-detect-project
Итоговый проект в рамках обучения на программе профессиональной переподготовки университета РУТ (МИИТ) по направлению "Искусственный интеллект", включающий в себя
- EDA обучающего датасета
- Собственный датасет для теста модели
- Дообученную модель YOLOv8n на задачу детекции автомобилей и пешеходов, и все связанные с этим файлы
- Тестирование и анализ модели
- Код телеграм бота, позволяющего взаимодействовать с моделью
